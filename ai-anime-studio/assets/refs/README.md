# Reference image inputs

Place approved character references here. Expected paths in `shotlist.motion_reference.example.json` are:
- `cat_model_front.png`: front/three-quarter view, clean silhouette and visible face.
- `cat_model_fullbody.png`: full body, centered, tail and all limbs visible.

The script does not create these assets. Use your chosen image-generation workflow, then review the images for model consistency before running video inference. Keep the same image for shots that must preserve identical character identity.
