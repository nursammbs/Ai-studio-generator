# Reference images for Wan Animate 2

The example manifest expects these generated files:

- `01_cheese_discovery.png`
- `02_chase_start.png`
- `03_kitchen_chaos.png`
- `04_final_gag.png`

They are included in the downloadable **Wan Animate 2 Motion-Transfer Starter Kit**. Copy those PNGs into this folder (or run `python generate_motion_guides.py` from `ai-anime-studio/` after placing the source sprite sheets in `assets/source/`). Each image is a fixed first-frame composition matched to its corresponding driving clip. This starter reference contains both cat and mouse; group identity consistency is model-dependent and must be checked in the generated result.
